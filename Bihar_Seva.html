ग्राहक मोबाइल सत्यापन

ग्राहक मोबाइल नंबर दर्ज करेगा और OTP सत्यापन करेगा। SMS सेवा और सुरक्षित backend जुड़ने के बाद ही OTP भेजा जाएगा।

यह बटन असली OTP नहीं भेजेगा।

Admin द्वारा दी गई User ID

OTP सत्यापन के बाद Admin ग्राहक को Bihar Seva की अलग User ID और Password देगा। सरकारी पोर्टल के OTP या पासवर्ड कभी यहाँ न डालें।

अभी असली अकाउंट या लॉगिन सर्वर नहीं जुड़ा है।
